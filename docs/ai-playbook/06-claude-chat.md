# Lesson 6: claude.ai chat, advisor and challenger

## 6.1 Its role

* Independent advisor and critic. It does not build, merge, change production config or direct builders.
* Best uses: red-team a plan before money or weeks go into it, compare options honestly with probabilities, review a decision brief, and write messages the Founder sends as himself (it has his voice skill).
* It is the same model family as Claude Code. For code review, Codex is the more independent reviewer. For plans and strategy, claude.ai and ChatGPT disagreeing is useful signal.

## 6.2 What it can do that helps Muse

* Memory of the Founder's projects and preferences across chats, plus past chat search.
* Web research with sources.
* Can usually read public GitHub repos (the Genesis repo is public), so a relay packet can link files instead of pasting them. If it cannot open a link in that session, the Founder pastes the file.
* Can produce docs, sheets, slides and designs the Founder can share.

## 6.3 How to ask it

Use a relay packet. Ask for:

1. A verdict first (go, change, stop).
2. The strongest argument against the current plan.
3. An honest probability or confidence where it applies.
4. The one change that would most improve the plan.

## 6.4 Founder preferences to respect in anything for him

* Direct and structured, numbered steps and tables.
* No dashes as punctuation in written output.
* No unsolicited advice outside what was asked.
* English by default, Spanish when he writes in Spanish.
* He does not want claude.ai artifacts for trackers or tools. Those go into his own apps (for example the Tyburon app).
