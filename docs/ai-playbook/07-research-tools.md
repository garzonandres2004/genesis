# Lesson 7: research tools (Perplexity, Gemini, deep research)

Verified 2026-11-09. Plans and limits change often.

## 7.1 Which research tool for what

| Need | Best first tool | Why |
|---|---|---|
| Fast facts with citations (prices, competitors, regulations) | Perplexity Pro | Citation-first answers, multi-model |
| Long multi-source report | Perplexity, Gemini or ChatGPT deep research | All three offer it. Run two on important questions and compare |
| Long PDFs, videos, screenshots, big documents | Gemini | Large context and strong multimodal input |
| Questions inside Google Docs, Drive, Gmail | Gemini app | Native Workspace access |
| Things Muse can do itself | Muse browser | No relay needed |

## 7.2 Access in Genesis today

* Perplexity Pro and Gemini Pro are browser subscriptions with no API. The capability matrix lists both as "not established": no login for Muse, terms not checked. Until the Founder decides (lesson 13), use them only through relay packets.
* Do not script around a browser subscription's terms or limits. Policy section 3 forbids bypassing usage limits or provider restrictions.

## 7.3 Gemini API (the free key)

* As of November 2026 the free tier covers Flash and Flash-Lite class models. Pro models are paid.
* Google's API terms allow free tier inputs and outputs to be used to improve its products, and human reviewers may read them. Confirm in the current terms before use.
* **Rule:** no bank statements, account numbers, family financial records or any personal data on the free tier. Family Wealth OS statement reading needs a paid tier with the right data terms, or a different provider. This is a Founder decision because it costs money.
* Good free tier uses: tagging public data, summarizing public pages, cheap classification of non-sensitive text.
* The key must be installed through the secure flow, never pasted into a file or memory.

## 7.4 Research quality rules

1. Open the top sources yourself and check that they say what the summary claims.
2. Prefer primary sources: official docs, filings, government sites, vendor pricing pages.
3. Write the date next to every fact that can change.
4. If two tools disagree, report both and say which source is stronger.
5. Separate facts from the model's opinion in the final write-up.
